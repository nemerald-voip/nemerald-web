Using the mobile app, you can send a text message to a colleague directly via ‘**Personal**’ chat or to a group of colleagues using a ‘**Group**’ chat.

The ‘**Chats**’ tab is where all of your chat conversations - all the messages you’ve sent and received, are displayed.

It is also where you can create a new ‘**Personal**’, ‘**Group**’, or ‘**SMS**’ chat.

You can initiate a chat with a colleague using one of the following options:

- Open your colleague’s [Profile](/docs/apps/ios-working-with-contacts--fkd2qyccst8qw7mnpdkeyppp) . And pressing the**chat**__icon__.

* Select an existing chat in the ‘**Chats**’ tab.

- Create a new chat by pressing on the![App icon](/img/ringotel/original/c4c15a8e5eb3ee1b8b03/fa3a72562096b836374e36cd269b0df33a7f0e2f9e4e5848d2541289d92ba5fc.png)icon at the top right corner of the screen and then selecting the type of chat you would like to create.
