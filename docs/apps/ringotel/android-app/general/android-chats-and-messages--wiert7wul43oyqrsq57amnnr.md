Using the mobile app, you can send a text message to a colleague directly via ‘**Personal**’ chat or to a group of colleagues using a ‘**Group**’ chat.

The ‘**Chats**’ tab displays all your chat conversations and all the messages you’ve sent and received.

It is also where you can create a new ‘**Personal**’, ‘**Group**’, or ‘**SMS**’ chat.

![](/img/ringotel/original/aab139187a76b3b2dc9b/a7f20bf58bde478271a463168cbc53177cf9fa5c812bb055110699e93a028df3.png)

You can initiate a chat with a colleague using one of the following options:

- Open your colleague’s [Profile](/docs/apps/android-working-with-contact--ukprk9ontafcdkvwcit3mzs6) . And pressing the **chat icon**.

* Select an existing chat in the ‘**Chats**’ tab.
* Create a new chat in the ‘**Chats**’ tab by pressing the![App icon](/img/ringotel/original/5c216d41c20b25c70472/39dd17861b340716bbd4622a4146d79ced0b8559501f20d8979465a49ccaa3ac.png)icon at the bottom of the screen and then selecting the type of chat you want to create.
