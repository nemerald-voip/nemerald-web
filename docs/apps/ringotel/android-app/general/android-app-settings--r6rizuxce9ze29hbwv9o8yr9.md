In the App Settings, you can set Call Forwarding, Voicemail, and other features according to your needs.

To open the App Settings, switch to the **Menu tab&#x20;**&#x61;nd select the **Settings&#x20;**&#x6D;enu item.

Here you can set the following options:

**Autoload photos/images.**&#x54;his feature lets the app preload all the images in your personal and group chats.

**Make or receive calls with Android Auto.**&#x45;nabling this feature will allow you to make and receive calls while in a car using Android Auto.

**Ringtone.**&#x48;ere you can set the ringtone for all calls coming to the Nemerald app.

**Open web pages in an external browser. When enabled, all custom web pages&#x20;**&#x74;hat a user has in the menu tab will be opened in an external browser instead of the in-app one.

**The call&#x20;**&#x73;ettings menu is where you can set up Call forwarding and your personal Voicemail.

**Report an issue**. While we are trying our best to make the perfect app, there may be times when you will encounter an issue or a ‘bug’. For those times, please use this feature and send us information about the issue you’ve experienced. Our support team will do our absolute best to find the resolution as soon as possible.

**Version.**&#x48;ere is where you can find the version of the app you are using right now.
