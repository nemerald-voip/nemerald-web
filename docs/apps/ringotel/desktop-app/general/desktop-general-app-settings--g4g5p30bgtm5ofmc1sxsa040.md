You can configure a pop-up window during incoming calls and voicemails, trigger auto-recording of all calls as well as set the storage location for records in the General section. All forwarding rules, as well as enabling the possibility to receive a second call can be set in Call settings. Device selection for speakers and microphone in the Audio section. All camera-related features for video calls can be found in the Video section.

![](/img/ringotel/original/2344e24e1bd094c8ca53/4fab504b15db28932752a2f5562550a056371d35abeec0b98968dc0664786a28.png)

1. Variants of pop-up window during incoming calls.
2. Turns automatic pick-up of incoming calls after a specified period on/off.
3. Opens custom web pages in an external browser or within the app.
4. Import a list of contacts from a CSV file into the app.
5. Turns notifications about external audio devices' connection on/off.
6. Enables recording of all calls. \*
7. Allows to store copies of call records on a local hard drive. \*

*\* Please check the availability of this feature with your PBX Administrator.*
