To send a file:

1. Open the chat with the person you want to send the file to.
2. Click on the![App icon](/img/ringotel/original/88f647d88efbffa6b9e1/8a49c95a4a3b7f56a8f65e02e00f5adc435dcded4ea21f2333b1d9a6f3e250b8.png)icon at the right side of the **Message Input Area**.

![](/img/ringotel/original/2c06cbff059902aec600/b9ef4e3c87f55815df5d0e4bf5712c46d9e5a27b1739b33c230768ace0b8aef1.png)

1. Choose a file you would like to send.

You can also use **drag-n-drop&#x20;**&#x74;o send files into a chat and send files, images, and text from your clipboard by pressing **Ctrl-V&#x20;**&#x69;n the **Message Input Area**.
