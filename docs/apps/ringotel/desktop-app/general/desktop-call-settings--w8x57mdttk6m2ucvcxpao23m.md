## PBX features and forwarding rules

Your desktop app can receive multiple calls simultaneously. The number of calls the app can receive is specified in the Number of inbound lines box in the Calls Settings tab. However, you will need to enable the **Call Waiting&#x20;**&#x66;unction first. If **Call Waiting&#x20;**&#x69;s enabled, the number of inbound lines will be set to 2.

![](/img/ringotel/original/6f522fb162f0faa3249f/fb2fede27af16692b082b03176f472a6c4bd9024ebfb78ab43d11c134c397a01.png)

1. **Call Waiting&#x20;**&#x61;llows you to suspend an existing phone call to answer a second call.
2. Enable/disable voicemail.
3. Turns ON/OFF unconditional forwarding of all your calls to the phone number set below.
4. **Turn ON/OFF call forwarding&#x20;**&#x74;o the following number, in case you are not answering the phone within a set number of seconds.
5. Number of calls the app can receive simultaneously.
6. Turns ON/OFF forwarding to a phone number when your app is offline.
7. Turns ON/OFF call forwarding to a phone number when all your lines are Busy.
