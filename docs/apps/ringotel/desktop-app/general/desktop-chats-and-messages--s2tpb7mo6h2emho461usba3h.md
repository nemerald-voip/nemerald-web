Using the desktop app, you can send a text message to a colleague directly via ‘**Personal**’ chat or to a group of colleagues using a ‘**Group**’ chat.

The ‘**Chats**’ tab is where you can find all your chat conversations and all the messages you’ve sent and received.

This is also where you can create a new ‘**Personal**’, ‘**Group**’, or ‘**SMS**’ chat.

![](/img/ringotel/original/073139bba2b7b7bcfbb5/8c1182f61724e8ebd456ee92080bd3bd61fe1278de7c479fbf2ab2d58168ccea.png)

## How to pin a chat in the list

To pin a chat:

1. Click on the![App icon](/img/ringotel/original/7c10737329d19d59e3b4/6c4a75a00c5a57de9bded1029d1a4493fc8c2d6b76f174e4f44f4d38ed45f528.png)icon at the top side of the **Chat panel.**
2. Select **Pin chat**. Now, this chat will be listed above the others.
3. Do the same procedure to unpin chat.

![](/img/ringotel/original/797188c7db56790d3b3d/1ffad9df95fb92416301bc1e2b69b98ee1df00f0993e64ad92a98dc04f4eee3c.png)

**\* Please check the availability of this feature with your PBX Administrator.**
