You can search for information in chat using various filters:

1. Click on the![App icon](/img/ringotel/original/7c10737329d19d59e3b4/6c4a75a00c5a57de9bded1029d1a4493fc8c2d6b76f174e4f44f4d38ed45f528.png)icon near the username or chat name.
2. Select **Search&#x20;**&#x66;rom the drop-down menu.

![](/img/ringotel/original/8b8c33f4072b16acd682/9f0cc20b85704d61002c46f641e473afbb0a6cec7eff7d9e7e71d1501caa77d3.png)

1. In the **Search&#x20;**&#x61;rea type a keyword to search for a message.

![](/img/ringotel/original/ab362ca73fc0d5e45134/7390204588ad6c1c357ef1d3ed1e87184f2889dd8fb6e979f14df9f72d7b6665.png)

You can filter search results by:

![App icon](/img/ringotel/original/5a2a5d932a6af431db94/36919ab19f33a3988fadf2e858d657f8a37cf4c29edcc977845d3196c79a0c65.png)- show only calls.

![App icon](/img/ringotel/original/a5e58d1c410b4ef99699/c0fab44452eb32cd3c38ab5c6ef4c6b2eb72eafffeb5abb7f8099374af82253d.png)- show only favourite calls and messages.

![App icon](/img/ringotel/original/14335f650e5ec5c2a150/6e05eb865c5234bfbc1cf8f88dfa160e0ac6189aacb346e0a9c9d4927362e494.png)- show only messages containing web links.

![App icon](/img/ringotel/original/4d229f9264f32fea3710/88ce681aa369080ce5eb460a295be3a2c0b4fe84967ae8ce72828f5b24a0764b.png)- show only files.

You can jump to the timestamp of the searched result by clicking on the![App icon](/img/ringotel/original/18774bc3b39f63765a2b/87e5207e9e9ab7299d7a15aa0fc59baae11cf020e4198862c18773d8eca9bae7.png)icon and selecting Go To in the drop-down menu.
